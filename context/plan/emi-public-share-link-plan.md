# EMI Public Share Link — Module Design Plan

**Project:** Emitrax
**Scope:** A copyable link that shows one EMI's details and amortization schedule, read-only, without login
**Status:** Shipped (phases A–D). Migration applied and verified 2026-10-14. Checked end to end in a browser 2026-10-14.

---

## 1. Goal

An EMI owner copies a link and sends it to someone (family member, co-borrower,
accountant). The recipient opens it and sees the EMI's details and its
amortization schedule. No account, no login, no edits.

Non-goals (this version):

- Rich link previews (Open Graph per EMI): needs a Vercel edge function
  because the app is a client-rendered SPA. Deferred to a later version.
- Splits, scenarios, share list or notes on the public page.
- Expiring links.

## 2. Confirmed decisions

1. **Content:** EMI details + amortization schedule only.
2. **Lifetime:** a link lives until the owner revokes it. No expiry.
3. **Formatting:** the owner's number style (`locale`, `number_format`) with
   the EMI's own currency, so the viewer sees exactly what the owner sees.
4. **No per-link previews** for now.

Defaults chosen during design (change here first if they should differ):

5. **One live link per EMI.** Revoking it and creating a new one issues a
   fresh token; the old URL stops working.
6. **Owner only.** Users the EMI is shared with (even with write) cannot
   create or revoke public links.
7. **`notes` is not exposed.** Free text that users treat as private. `tag`
   is exposed.

## 3. Security model

RLS cannot express "whoever holds this token". So:

- `anon` gets **no** table access: not to `emis`, `amortizationSchedules`
  or `emiShareLinks`.
- `anon` may call exactly one function, `get_public_emi(token)`,
  `SECURITY DEFINER`. It validates the token and returns an **allow-listed**
  JSON payload, never whole rows. `userId`, `notes`, splits, shares and
  scenarios never leave the database.
- Tokens are 192 random bits (base64url, 32 chars), generated by a trigger
  on insert. A client cannot choose a weak token or rewrite an existing one;
  updates may only change `revokedAt`.
- Unknown and revoked tokens both return `NULL`, so a probe learns nothing.
- Deleting an EMI cascades to its links.

## 4. Schema — `supabase_emi_public_share_links.sql` (hand-run first)

- `emiShareLinks`: `id`, `"emiId"` → `emis` CASCADE, `token` UNIQUE,
  `"createdBy"`, `"createdAt"`, `"revokedAt"` (nullable).
- Partial unique index: one row per `"emiId"` where `"revokedAt" IS NULL`.
- Trigger `set_emi_share_link_token()`: generates the token on insert, and
  freezes `token`/`emiId`/`createdBy`/`createdAt` on update.
- RLS, four policies, all via `check_emi_ownership("emiId", auth.uid())`.
- `get_public_emi(p_token text) RETURNS jsonb`:
  `{ emi: {...}, schedule: [...], format: { locale, numberFormat } }`.
  `EXECUTE` granted to `anon, authenticated`; revoked from `PUBLIC`.
- The script ends with a VERIFY block. Run it before phase B.

## 5. App changes

### Phase B — data layer

- `src/supabase/supabase.types.ts`: `emiShareLinks` Row/Insert/Update and
  the `get_public_emi` function signature.
- `src/types/emi.types.ts`: `IEmiShareLink`, `IPublicEmi` (emi, schedule,
  format).
- `src/utils/EmiShareLinkService.ts`: `getActiveLink(emiId)`,
  `createLink(emiId)`, `revokeLink(id)`, `fetchPublicEmi(token)` (the RPC).
  Throws on error, `map*Row` coercion.
- `src/hooks/useEmiShareLinks.ts`: `emiShareLinkKeys` factory;
  `useActiveShareLink`, `useCreateShareLink`, `useRevokeShareLink`,
  `usePublicEmi(token)` (no `userId` gate).

### Phase C — public page

- Route `/s/:token` registered **outside** `<Layout />` in
  `src/router/HomeRouter.tsx`, beside `/auth/callback`: no sidebar, no
  account bootstrap, no auth redirect.
- `src/router/pages/PublicEMI.tsx`: header with item name + a small
  "Shared via Emitrax · read-only" line; the details summary; the schedule
  table. Reuse the existing presentational pieces where they take data by
  props; where they reach into hooks/Redux, pass data in rather than
  duplicating them.
- Formatting: the page must not use the viewer's Redux preferences.
  It wraps itself in `NumberStyleProvider` (`src/context/NumberStyleProvider/`)
  with the payload's `format`. `useCurrencyPreferences` prefers that
  override over the store, so shared components (`RepaymentProgressCard`,
  `AmortizationTable`) render in the owner's style unchanged.
- Not-found state for a `NULL` payload: "This link is no longer available."

### Phase D — owner UI

- On `/emi/:id/share`, a "Public link" card above the user shares:
    - No link → "Create link" button
    - Live link → read-only URL field, **Copy**, **Revoke** (with confirm)
- Copy uses `navigator.clipboard.writeText` + a success toast.
- Only rendered for the EMI owner.
